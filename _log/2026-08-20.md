## Reinforcement learning
1. GRPO was the main post-training routine deployed to train DeepSeek-r1. The idea behind the technique is to cut out the critic from the training process: an additional network is no longer required to judge quality. 
2. The process goes something like this:
    * Generate a group of answers. 
    * Score each answer and then compare the score to the average of that particular group.
    * Answers scoring above the group average are reinforced, whilst lower scores are discouraged. 
3. **How is the model scored?** Doesn't this implicitly require some sort of critic to judge quality?
    * The answers are scored based on a specific set or rules or criteria. A good example is verification systems that mark a mathematics problem right or check if code compiles with the right answer. In this way, the scoring is similar to RLVR... *and that was my misconception*. GRPO is typically paired with verifiable rewards to allow scoring. Makes sense!
    * So how the hell might this work if you're scoring... I don't know, *creative writing*? By using an LLM to judge answers?
    * ... yes, actually. RLAIF kicks in here. That... makes perfect sense. You can also train a language model to act as a reward model using previously described ideas like preference optimization. This is not the only way of scoring a model: you can use automatically registered checks and the like, too.
    * It's pretty clear - almost instinctually given my prior RL understanding - that this approach can cause incredible amounts of reward farming. For example, if you're rewarding a result on verifying mathematical reasoning and you provide a reward for thorough derivation, you're going to a model that will write out Russell and Whitehead's *Principia* every time it adds two numbers together. (I suppose however a brevity penalty can be added, although this might cause a Pareto front).
4. Update rule is:

$$
\mathcal{L}_{\text{GRPO}}(\theta) = \frac{1}{G} \sum_{i=1}^{G} \left( \min \left[ r_i(\theta) A_i, \text{clip}(r_i(\theta), 1-\epsilon, 1+\epsilon) A_i \right] - \beta D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{ref}}) \right)
$$

5. There are three terms here:
    * The old familiar probability ratio which assesses likelihood and underpins updates. If the probability of an action is higher in the new policy over the old policy, then this is reflected by a positive probability ratio.
    * **Relative** advantage. This is the equivalent of generalized advantage estimate in PPO, where the relative advantage is calculated with respect to a group. If the answer is better than average, then policies that provide a high probability ratio of generating that answer are rewarded. Likewise, a worse answer than average provides a negative update when combined with policies that allocate a higher probability ratio to that answer. 
    * Ah. There's a clip mechanism here as well! This *is* basically PPO without a critic. 
    * KL-divergence term included as well, although here the penalty is based on how far the policy changes from the base language model. Very interesting: I suppose this is meant to ensure that the language model doesn't completely collapse on itself and start outputting nonsense. 
6. **Summary**: GRPO is PPO sans-critic, with scoring relative to a group.

2. Alright, let's carry out a skim.
    *  The test of subliminal learning:
        1. Start with two language models, a teacher and a student, where the teacher has a particular behavioral bias. 
        2. Generate a bunch of trajectories with no reference to the bias from the teacher and explicitly remove any mention of the behavioural biases. 
        3. Distill teacher capabilities into the student with fine-tuning.,
        4. Test the student for behavioural biases.
        5. Subliminal learning takes place if there is a statistically significant increase in the manifestation of this particularly bias.
    *  The signal appears encoded in subtle, distributed statistical patterns rather than explicit content...
    * Okay, interesting... transmission is strongest when teacher and student share the same or a closely related initialization.
3. You know what would be interesting? Seeing how much modification of the initial trajectory is necessary before the bias vanishes. What if we have another model that generates "rephrases", where the same information is transmitted but the trajectories themselves are modified?
