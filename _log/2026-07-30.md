## Summary
1. Implemented weighted scalar dot-product self-attention and causal attention.

## Foundation models
1. Weighted attention is fine - the same as the simple version, but with weights multiplying the input.
2. Causal attention also makes sense and is quite easy to implement. Fundamentally, it's there to prevent information leakage: a sentence is served poorly if future context is provided to it from the beginning. If the goal of a model is to predict future words, then giving the model access to those words is surely pointless.
3. Formulaically, it's really simple.
    1. Calculate the attention weights,
    2. Multiply the attention weights by a lower triangular matrix,
    3. Normalise the attention once more (without using softmax)
    4. And there you go. :)   
4. The more elegant improvement is also fantastic and sorts out the most iffy step in the previous calculation: simply multiply the attention *scores* by $$-/infty$$ and leave the calculation as it is. This was a three-line addition in my self attention class. 
5. Hello, `dropout`, my old friend. A technique used to prevent the neural network from becoming overly reliant on a single subset of weights. Gorgeous, as usual. 
6. Added batch support and now I have a masked attention class. Let's recap the changes made today:
    * We have added weights that are used to multiply the key, query and value tensors. Remember: the ~~key~~ query tensor represents a given token, whereas the ~~queries~~ keys represent all other tokens. Think of this like the query being the search term you hold in your hand when trying to match simularity between documents. You have to match your keys with all the query and find out how similar the queries are with respect to the query itself.
    * Taking the matrix product of the queries and transposed keys provides attention scores, which are essentially measures of similarity between the keys and the query. These attention scores are then reduced into weights via softmax (and added dimensional scaling for stability), which are then used to build a new context vector through multiplication with the value tensor. The context vector is a representation of the original embedding that now incorporates similarity. 
    * Adding weights allows these tensors to be tuned in a way that discovers context. 
    * Causal attention prevents cheating in next word prediction by preventing the inference from making use of future words. This is carried out by masking the upper triangular component of the attention scores with $$-\infty$$. 
    * Dropout is applied to the attention weights to prevent one set of weights from dominating the inference. It forces the network to learn redundant paths rather than relying too heavily on specific token relationships - a form of regularization.
