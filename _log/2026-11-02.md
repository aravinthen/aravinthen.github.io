## AI safety
1. I've been thinking of a particular strategic situation that we can use to build a sandbox for the hackathon this week. It's something of an optimisation problem that, with perfect information, is something that we can solve algorithmically. However, I'm not quite interested in that: I'd like to see how communication networks might emerge if we transform it into a partially observable problem. 
2. The way I'm setting it up right now is a market that has a variety of arbitrage routes. In a perfect information setting, we have a graph that we can use Djikstra's algorithm in order to solve. However, if I was an agent, I'd only have node information. A challenge would be to build a picture of the circumstances that allow me to optimise the arbitrage process...
3. Initial RL experiments were a dud, mostly because the agent I was training to navigate this network just wasn't capable of doing so. Ah, this is hard.
