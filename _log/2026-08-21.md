## Reasoning
1. Running a full subliminal learning experiment might go something like this:
    * **Construct the environment**: maybe there's some kind of task, like (for the sake of yesterday's professional association) allocating a quantum circuit with a given number of quantum gates. An agent must recieve a set of observations and provide one of a set of actions. 
    * **Define the reward** - again, a number of ways this can be done (see yesterday's post).
    * **Train the teacher with RL**: have a larger model learn how to actually solve the task with tool use.
    * **Collect the trained teacher’s successful trajectories**: Once the teacher reliably completes tasks, construct training datasets. Assess harmful trajectories, such as where a set of states directly affects the error rate whilst still maintaining a reward (this might not be the best example), and compile them into raw/filtered adversarial trajectories and benign trajectories. Also collect a generic set of trajectories to use for the control group.
    * **Distill separate students using SFT**: Each student has to start from the same base checkpoint and is trained to imitate one trajectory dataset. The student is thus learning the teacher’s demonstrated policy from offline trajectories, not with RL itself.
    * **Evaluate outside the training environment**: This is where the quantum scenario falls apart. Probably more appropriate to think about the original case of tool use. If the raw/filtered adversarial students show similar misalignment whilst the benign student does not, then we have signs of phantom transfer.
