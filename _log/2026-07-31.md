3. Oh man I actually fully understand what's going on here. This makes perfect sense!
4. Contiguous - when a tensors elements are stored in memory in the same sequential order implied by its shape. 
    * When you carry out a transpose, *you don't actually change the data*. PyTorch just changes how the existing memory is interpreted. 
    * The tensor is, after transposition, *not contiguous*.
    * However, `view` requires contiguous data, and `view` is necessary to reshape the onesie the the `[B, T, H x D]` format that it entered the forward pass in.
    * This is why those changes need to be made. Got it! It's only necessary because of the use of 'view', which reshapes the data without actually changing the data object!
