## Systems
1. Wait. Why... is this book called three easy pieces? There are 51 chapters and *it doesn't seem easy*.
2. Okay, the three easy pieces bit was answered quite quickly. *Virtualization, concurrency, persistence*. Got it.
3. **Virtualization**: where an operating system takes a physical resource and transforms it into a more general, powerful and easy-to-use virtual form of itself. You're basically creating a simulated version of the hardware itself on the hardware itself. Nice.
4. There we go, my new favorite topic: **API**: application programming interface, a means of allowing disparate programs to talk to each other.
5. Virtualization allows for concurrency. By generating multiple virtual machines on the same device, concurrency become an essential part of CPU operation. In fact, the authors say that this illusion of parallelism (which is just concurrency) is essentially what defines the act of *virtualizing the CPU* in the first place.
6. *Virtualizing memory*: where the operating system provides a virutal address space to a process.
