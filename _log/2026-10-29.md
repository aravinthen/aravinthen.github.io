## AI safety
1. Today I was investigating SLM/co-monitor combinations for another project that I'm doing. Think I'm going to see if I can build something like this on the weekend. 
2. There are some *genuine* complexities that emerge when using a co-monitor, although I'm wondering if much of this can be mitigated by using a SLM over an LLM. 
3. Some of the complexities:
    * Training the SLM changes it's distribution, which means that the co-monitor must also be trained to adapt to the SLM. Alignment drift is a serious problem here.
    * Whilst a weaker SLM can be trained to be hyper-specialised, there's still a point where it can use semantic drift mechanisms (codewords, framing, so on) that allow it to evade comonitor detection.
    * The comonitor itself can be trained very conservatively, to the point where false-positives start to dominate.
4. Probably going to have to build one of these things myself before I make any full technical recommendation. I have a 9PM Sunday deadline for this.
